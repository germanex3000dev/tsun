# tsun - The minimalistic tsundere text editor

It saw that many terminal, or minimalistic were missing a very important feature: 
A tsundere personality. This is why I created tsun. An extremely minimalistic text editor
that has a tsundere personality
> Although calling it a "personality" is a really big take. It's not really, but who cares

> This README is going to be extremely low-quality. Expect changes, or don't idc.

## Main features
- **Opening files:** Yeah, I know big feature
- **Editing files:** Another, really big and unique feature
- **Saving files:** This feature makes it the next Notepad repalcer
- **Can Exit the program:** Literally better than vim/neovim. 
- **Has a tsundere "personality":** Now this is the main "feature" of this

### The tsundere "personality"

The tsundere personality is very simple:
- On opening, exiting, aborting and saving files, it says one of the random sentences I pre-programmed
  - So no sophisticated AI, I know. I'm working on it
- Aborting, so Ctrl+C, makes it refuse 2 times, each time making her angrier, and on the 3rd try letting you abort with a tsundere reaction
- There is a chance of her refusing to open a file. It is about 15% on default mood
  - The chance of refusal goes higher with worse mood.

The moood:

| mood | refusal chances |
|------|-----------------|
| 0 (max mad) | 35%      |
| 40 (defualt) | **15%** |
| 68   | 1%              |
|>= 70 | 0% (never)      |

saves cheer her up, refusals (^C) attempts tick her off
